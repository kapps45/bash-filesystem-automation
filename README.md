# 🐚 Bash File System Automation

Небольшой Bash-скрипт для автоматизации операций с файловой системой.

Скрипт последовательно создаёт структуру каталогов и файлов, изменяет права доступа, формирует отчёт на основе содержимого каталогов, запускает вложенный shell-скрипт и удаляет временную структуру после завершения работы.

## 📌 Назначение

Проект демонстрирует базовые возможности **Bash** для работы с файлами и каталогами, а также показывает, как объединять отдельные команды в последовательный сценарий автоматизации.

## 🔧 Что делает скрипт

В процессе выполнения `precode.sh`:

1. 📁 Создаёт вложенную структуру каталогов
2. 📄 Добавляет пустой файл и исполняемый Bash-скрипт
3. 🔐 Устанавливает права доступа `764` для созданного скрипта
4. 📋 Сохраняет содержимое каталога в текстовый файл
5. 📂 Копирует файлы в другую директорию
6. 🔎 Собирает информацию о `.txt`-файлах с помощью `find`
7. 🔀 Объединяет результаты команд через перенаправление вывода
8. 📤 Передаёт значение переменной в отдельный Bash-скрипт
9. 📝 Формирует итоговый файл `Практическое задание`
10. 🔍 Выполняет поиск строк через `grep` и сортировку с помощью `sort`
11. 🗑️ Удаляет созданную временную директорию после завершения сценария

## 📁 Создаваемая структура

Во время работы скрипта формируется следующая структура:

    task/
    ├── dir1/
    │   └── summary.txt
    ├── dir2/
    │   ├── empty
    │   ├── hello.sh
    │   └── list.txt
    └── dir3/
        └── dir4/
            ├── empty
            ├── hello.sh
            └── list.txt

После выполнения всех операций каталог `task` удаляется.

## 🛠️ Используемые команды

Проект использует стандартные Unix-команды и возможности **Bash**:

- `mkdir` — создание каталогов
- `cd` — переход между директориями
- `touch` — создание файла
- `chmod` — изменение прав доступа
- `ls` — получение списка файлов
- `cp` — копирование содержимого
- `find` — поиск файлов по шаблону
- `cat` — чтение и объединение содержимого
- `grep` — фильтрация строк
- `sort` — сортировка результата
- `mv` — перемещение и переименование файла
- `rm` — удаление временной структуры
- `>` и `>>` — перенаправление вывода в файлы

## ▶️ Запуск

Для выполнения сценария используйте:

    bash precode.sh

Либо сделайте файл исполняемым:

    chmod +x precode.sh
    ./precode.sh

> **Важно:** скрипт создаёт и удаляет временный каталог `task` в текущей директории. Перед запуском рекомендуется убедиться, что в рабочем каталоге нет важных данных с таким именем.

## 📋 Требования

- **Bash**
- Unix-подобная операционная система: **Linux** или **macOS**
